1과목 요약노트: 데이터 이해 (10문항)

1과목은 개념 구분 문제가 대부분이라 용어를 정확히 구분하면 만점도 가능합니다.

데이터와 정보

  • DIKW 피라미드: 데이터(객관적 사실) → 정보(데이터 가공, 의미 도출) → 지식(정보를 구조화한 패턴, 규칙) → 지혜(지식에 통찰을 더한 창의적 아이디어)

  • 마트 예시: A마트 700원, B마트 800원은 데이터, A마트가 더 싸다는 정보, A마트에서 사야겠다는 지식, A마트의 다른 상품도 싸겠다는 지혜

  • 데이터 유형: 정량적(숫자, 수치) vs 정성적(언어, 문자), 정형(DB 테이블) / 반정형(JSON, XML, HTML) / 비정형(텍스트, 영상, 이미지)

  • 암묵지 vs 형식지: 암묵지는 개인에게 체화된 지식, 형식지는 문서·매뉴얼로 표현된 지식

  • SECI 모델 (암묵지↔형식지 변환): 공통화(암묵→암묵), 표출화(암묵→형식), 연결화(형식→형식), 내면화(형식→암묵)

데이터베이스와 기업 시스템

  • DB 특징: 공용 데이터, 통합된 데이터, 저장된 데이터, 변화되는 데이터

  • OLTP: 실시간 거래 처리, OLAP: 다차원 분석을 위한 대화식 분석

  • 기업 시스템: ERP(전사적 자원 관리), CRM(고객 관계 관리), SCM(공급망 관리), KMS(지식 관리), BI(경영 의사결정 지원 분석), EDW(전사 통합 데이터 웨어하우스)

  • 데이터 단위 순서: KB → MB → GB → TB → PB → EB → ZB → YB (1024배씩 커짐)

빅데이터

  • 3V: Volume(규모), Variety(다양성), Velocity(속도). 확장하면 Value(가치), Veracity(신뢰성)를 더해 5V

  • 출현 배경: 산업계(데이터 축적), 학계(대규모 데이터 분석 기법), 기술(저장 비용 하락, 클라우드, 분산처리)

  • 빅데이터 비유: 석탄·철 → 원유 → 렌즈 → 플랫폼

    • 산업혁명의 석탄·철: 생산 요소로서 중요성

    • 원유: 사회와 경제 전반을 변화

    • 렌즈: 세상을 보는 새로운 관점

    • 플랫폼: 공통 기반으로 다양한 서비스를 만듦

데이터 사이언티스트

  • 하드 스킬: 빅데이터 이론 지식, 분석 기술 숙련

  • 소프트 스킬: 통찰력 있는 분석, 설득력 있는 전달(스토리텔링), 다분야 간 협력

  • 핵심 역량: 분석뿐 아니라 인문학적 통찰(호기심, 스토리텔링, 커뮤니케이션)도 중요

개인정보 보호

  • 데이터 3법: 개인정보 보호법, 정보통신망법, 신용정보법 개정으로 가명정보 개념 도입

  • 비식별화 기법 5가지: 가명처리, 총계처리, 데이터 삭제, 데이터 범주화, 데이터 마스킹

  • 개인정보 보호: 정보 주체의 동의를 받아야 하는 것이 원칙이며, 가명정보는 통계 작성·연구 등 목적으로 동의 없이 활용 가능

  • 빅데이터 변화 4가지(사전→사후, 표본→전수, 질→양, 인과→상관)는 짝으로 암기

  • 비식별화 5가지 기법 이름과 설명 연결

2과목 요약노트: 데이터 분석 기획 (10문항)

2과목은 방법론 단계 순서와 용어 짝 맞추기가 핵심이라, 순서를 통째로 외우면 점수가 나옵니다.

분석 기획의 4가지 유형

분석 대상(What)과 분석 방법(How)을 아는지 모르는지로 나눕니다.

방법(How)을 안다방법(How)을 모른다
대상(What)을 안다최적화 (Optimization)솔루션 (Solution)
대상(What)을 모른다통찰 (Insight)발견 (Discovery)

  • 분석 기획 시 고려사항: 가용 데이터, 적절한 유스케이스 탐색, 장애요소 사전 계획 수립

  • 접근 방식: 과제 중심의 단기 접근(Quick-Win)과 마스터플랜 중심의 장기 접근을 균형 있게

분석 방법론

  • KDD (5단계): 데이터셋 선택 → 데이터 전처리 → 데이터 변환 → 데이터 마이닝 → 해석과 평가

  • CRISP-DM (6단계): 업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개 (단계 간 피드백으로 반복)

  • SEMMA (SAS): Sample → Explore → Modify → Model → Assess

  • 계층적 프로세스 모델: 단계(Phase) → 태스크(Task) → 스텝(Step)

  • 개발 모델: 폭포수(순차적), 프로토타입(시제품 반복), 나선형(위험 분석 + 반복)

빅데이터 분석 방법론 (5단계)

  1. 분석 기획: 비즈니스 이해와 범위 설정, 프로젝트 정의와 계획 수립, 프로젝트 위험계획 수립

  2. 데이터 준비: 필요 데이터 정의, 데이터 스토어 설계, 데이터 수집과 정합성 점검

  3. 데이터 분석: 분석용 데이터 준비, 텍스트 분석, 탐색적 분석, 모델링, 모델 평가와 검증

  4. 시스템 구현: 설계와 구현, 시스템 테스트와 운영

  5. 평가 및 전개: 모델 발전계획 수립, 프로젝트 평가와 보고

분석 과제 발굴

구분하향식 (Top-down)상향식 (Bottom-up)
방향문제가 명확할 때, 문제 정의 → 해결문제 정의가 어려울 때, 데이터에서 출발
절차문제 탐색 → 문제 정의 → 해결방안 탐색 → 타당성 검토디자인 사고, 비지도 학습, 프로토타이핑 접근
특징비즈니스 모델 캔버스, 5-Forces 등으로 탐색시행착오를 거쳐 개선하며 발굴

  • 비즈니스 모델 캔버스 5영역: 업무, 제품, 고객, 규제와 감사, 지원 인프라

  • 디자인 사고: 발산(Diverge)과 수렴(Converge)을 반복

  • 프로토타이핑 접근: 일단 만들어 보고 반복 개선하는 방식, 문제를 정의하기 어려운 경우에 유용

  • 분석 프로젝트 관리 지식영역: 범위, 시간, 원가, 품질, 인력, 의사소통, 위험, 조달, 이해관계자, 통합 (PMBOK 10개 영역)

분석 마스터플랜과 로드맵

  • 우선순위 평가 기준: 시급성과 난이도. 시급성이 높고 난이도가 낮은 과제를 먼저 추진

  • 난이도 요소: 데이터 획득·저장·가공 비용, 분석 적용 비용, 분석 수준

  • ROI 요소: 투자비용 요소와 비즈니스 효과 요소

  • 로드맵 구성: 단계별 목표, 추진 과제, 이행계획

분석 거버넌스

  • 거버넌스 5요소: 조직, 프로세스, 시스템, 데이터, 인력(Human Resource)

  • 데이터 거버넌스 구성: 원칙(Principle), 조직(Organization), 프로세스(Process)

  • 분석 조직 구조: 집중형(전담조직이 전사 분석 수행), 기능형(각 부서가 분석 수행), 분산형(분석 인력을 현업 부서에 배치)

  • 분석 성숙도 단계: 도입 → 활용 → 확산 → 최적화

  • 분석 준비도 6영역: 분석 업무, 분석 인력과 조직, 분석 기법, 분석 데이터, 분석 문화, IT 인프라

3과목 요약노트: 데이터 분석 (30문항)

3과목은 30문항으로 비중이 가장 큽니다. 수식을 깊게 파지 말고 용어 정의, 결과 해석, 간단한 계산 위주로 준비하세요.

R 기초와 데이터 전처리

  • R 객체: 벡터 c(), 행렬 matrix(), 배열 array(), 리스트 list(), 데이터프레임 data.frame()

  • 자주 나오는 함수: mean, median, var, sd, summary, str, head, apply, sapply, lapply, paste, subset, merge, table

  • 결측값 관련: is.na()로 확인, na.omit()으로 제거, mean(x, na.rm=TRUE)처럼 옵션 사용

  • 패키지: install.packages("이름")로 설치, library(이름)로 불러오기

  • 척도 4가지: 명목(구분만), 순서(순위), 구간(간격 동일, 절대 0 없음), 비율(절대 0 있음)

  • 표본 추출: 단순랜덤, 계통, 층화(집단별 비례 추출), 군집(집단 단위 추출)

  • 결측값 처리: 완전 삭제, 평균·중앙값 대체, 단순 대치, 다중 대치

  • 이상값 판단:

    • ESD: 평균에서 3 표준편차 이상 벗어난 값

    • 사분위수: Q1 − 1.5×IQR 미만, Q3 + 1.5×IQR 초과 (박스플롯의 수염 밖)

  • 데이터 마트: 요약변수(합계, 평균 등), 파생변수(기존 변수를 조합해 만든 새 변수)

  • 기술통계: 평균, 중앙값, 최빈값, 분산, 표준편차, 왜도(비대칭 정도), 첨도(뾰족한 정도)

  • 상관분석: 피어슨(연속형, 선형관계), 스피어만(순서형, 비모수). 값은 −1~1이며 0에 가까울수록 선형관계 약함

통계 기초와 가설검정

  • 이산 분포: 베르누이, 이항, 포아송(단위 시간 내 발생 횟수), 기하

  • 연속 분포: 정규(평균 0, 표준편차 1이면 표준정규), 균일, 지수, t, 카이제곱, F

  • 중심극한정리: 표본 크기가 충분히 크면(보통 30 이상) 표본평균의 분포는 정규분포에 가까워짐

  • 가설검정 용어:

    • 귀무가설(H0): 차이가 없다는 가설, 대립가설(H1): 차이가 있다는 가설

    • 제1종 오류: H0이 참인데 기각, 제2종 오류: H0이 거짓인데 채택

    • 유의수준(α, 보통 0.05): p-value가 α보다 작으면 귀무가설 기각

  • 검정 선택:

상황검정
한 집단 평균을 기준값과 비교단일표본 t검정
같은 대상의 전후 비교대응표본 t검정
두 독립 집단 평균 비교독립표본 t검정
세 집단 이상 평균 비교분산분석(ANOVA, F검정)
범주형 변수 간 독립성카이제곱 검정
정규성 가정이 어려울 때비모수 검정(윌콕슨, 만-휘트니, 크루스칼-왈리스)

  • 추정: 점추정은 하나의 값, 구간추정은 신뢰구간(예: 95% 신뢰구간)

회귀분석

  • 단순회귀식: y = β0 + β1x + ε

  • 회귀 기본 가정: 선형성, 독립성, 등분산성, 정규성

  • 결정계수 R²: 모형이 설명하는 분산 비율(0~1), 변수를 추가하면 항상 커지므로 수정된 R²를 함께 봄

  • 검정: F검정은 회귀모형 전체 유의성, t검정은 개별 회귀계수 유의성

  • 다중공선성: 독립변수끼리 상관이 높은 문제. VIF가 10 이상이면 의심, 해결은 변수 제거, 주성분회귀, 릿지

  • 변수 선택: 전진선택, 후진제거, 단계적 선택. AIC, BIC는 작을수록 좋은 모형

  • 잔차 진단: 정규성(Q-Q plot, 샤피로-윌크 검정), 등분산성(잔차 대 적합값 그림), 독립성(더빈-왓슨)

  • 규제 회귀: 릿지(L2, 계수를 0에 가깝게), 라쏘(L1, 일부 계수를 0으로 만들어 변수 선택 효과)

  • 로지스틱 회귀: 종속변수가 범주형(이진), 결과는 0~1 확률, 오즈(성공확률/실패확률)의 로그를 선형식으로 모형화

  • R 회귀 결과표 읽는 법:

    • Estimate: 회귀계수, Std. Error: 계수의 표준오차

    • Pr(>|t|)가 0.05보다 작으면 해당 변수가 유의

    • Multiple R-squared: 모형 설명력, F-statistic의 p-value: 모형 전체 유의성

시계열 분석

  • 구성 요소: 추세, 계절, 순환, 불규칙 변동

  • 정상성 조건: 평균이 일정, 분산이 일정, 공분산이 시차에만 의존

  • 비정상 시계열 처리: 평균이 변하면 차분, 분산이 변하면 변환(로그 등)

  • 자기회귀 모형 AR(p): PACF가 p 시차 이후 절단, ACF는 서서히 감소

  • 이동평균 모형 MA(q): ACF가 q 시차 이후 절단, PACF는 서서히 감소

  • ARIMA(p, d, q): d는 차분 횟수, 차분 후 ARMA를 적용

  • 평활 기법: 이동평균법, 지수평활법(최근 관측값에 더 큰 가중치)

다차원 분석 (PCA, 요인분석, MDS)

  • 주성분분석(PCA): 변수들의 분산을 최대한 보존하며 차원 축소. 공분산행렬(또는 상관행렬)의 고유값이 큰 순서대로 주성분 선택

  • 주성분 개수 결정: 스크리 플롯의 꺾이는 지점(elbow), 누적 기여율 70~90% 확보

  • 요인분석: 변수 뒤에 숨은 잠재 요인을 찾음. PCA는 전체 분산 설명, 요인분석은 공통분산 설명

  • 다차원척도법(MDS): 개체 간 거리를 저차원 공간에 배치해 시각화. 스트레스 값이 낮을수록 적합도 좋음

데이터마이닝 개요

  • 지도학습: 정답이 있는 학습(분류, 회귀), 비지도학습: 정답 없이 패턴 발견(군집, 연관, 차원 축소)

  • 데이터 분할: 훈련 / 검증 / 테스트. 과적합(훈련에만 잘 맞음) 방지를 위해 교차검증, 가지치기, 규제 사용

  • 분류 기법: 로지스틱 회귀, 의사결정나무, KNN, 나이브베이즈, SVM, 인공신경망, 랜덤포레스트

의사결정나무와 앙상블

  • 분할 기준: CART는 지니지수, C4.5는 엔트로피(정보 이득), CHAID는 카이제곱 통계량

  • 과정: 성장 → 가지치기 → 타당성 평가 → 해석과 예측

  • 장점: 해석이 쉽고 비선형 관계 처리 가능, 단점: 데이터 변화에 불안정, 과적합 위험

  • 배깅(Bagging): 부트스트랩 표본으로 여러 모형을 병렬로 학습해 투표·평균. 랜덤포레스트는 배깅에 변수 무작위 선택을 더한 방식

  • 부스팅(Boosting): 오분류된 데이터에 가중치를 주며 순차적으로 학습. AdaBoost, GBM, XGBoost, LightGBM

  • 인공신경망: 활성화 함수(시그모이드, ReLU, tanh), 오차 역전파 학습, 층이 깊으면 기울기 소실 문제

  • SVM: 두 클래스 사이 마진을 최대화하는 초평면, 경계에 가장 가까운 점이 서포트 벡터

  • KNN: 가까운 k개 이웃의 다수결, 게으른 학습(lazy learning)

모형 평가 (혼동행렬)

예측 Positive예측 Negative
실제 PositiveTPFN
실제 NegativeFPTN

  • 정확도 = (TP + TN) / 전체

  • 정밀도 = TP / (TP + FP) (양성이라 예측한 것 중 진짜 양성)

  • 재현율(민감도) = TP / (TP + FN) (실제 양성 중 맞힌 비율)

  • 특이도 = TN / (TN + FP)

  • F1 점수 = 2 × 정밀도 × 재현율 / (정밀도 + 재현율)

  • ROC 곡선: x축은 1 − 특이도, y축은 민감도. 곡선 아래 면적 AUC가 1에 가까울수록 좋은 모형

  • 향상도 곡선, 이익도표: 상위 구간에서 모형이 무작위보다 얼마나 잘 맞히는지 확인

군집분석

  • 계층적 군집: 덴드로그램으로 표현. 연결법은 단일(최단), 완전(최장), 평균, 와드(군집 내 분산 증가 최소)

  • K-means: 군집 수 k를 미리 지정, 중심점 갱신 반복, 이상값에 민감

  • DBSCAN: 밀도 기반, 군집 수 지정 불필요, 이상값 탐지 가능

  • SOM: 자기조직화지도, 고차원 데이터를 저차원 격자로 시각화

  • 거리 척도: 유클리드, 맨해튼, 민코프스키, 마할라노비스(변수 간 상관 고려), 연속형이 아닌 경우 자카드 등

연관분석

  • 지지도(A→B) = A와 B가 같이 나올 확률 = P(A∩B)

  • 신뢰도(A→B) = A가 나왔을 때 B도 나올 확률 = P(B|A) = P(A∩B) / P(A)

  • 향상도(A→B) = 신뢰도 / P(B)

  • 향상도 해석: 1보다 크면 양의 연관, 1이면 독립, 1보다 작으면 음의 연관

  • 계산 예시: 전체 100건, A 40건, B 50건, A와 B 동시 20건이면 지지도 0.2, 신뢰도 0.5, 향상도 1.0 (독립)

  • Apriori 알고리즘: 빈발 항목집합을 단계적으로 찾고, 최소 지지도 미만 항목은 가지치기

빈출 포인트 한 줄 정리

  • 혼동행렬 계산(정밀도, 재현율)과 연관분석 계산(지지도, 신뢰도, 향상도)은 숫자 문제로 자주 출제

  • 의사결정나무 분할 기준(지니, 엔트로피, 카이제곱)과 배깅 vs 부스팅 차이는 짝으로 암기

  • R 회귀 결과표에서 유의한 변수와 R² 해석하는 문제는 거의 매회 출제

  • 정상성 조건과 ACF·PACF 절단 위치로 AR, MA 구분
